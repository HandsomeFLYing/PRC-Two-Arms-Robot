前言：
===

我最初接触魔方的时候是在初中，那时不知是谁先起的头，然后多数人都开始玩。我也不例外，花了一段时间学习，层先法挺简单的，只有几个公式，很快就学会了。后面高中也逐步学习，也了解了更多。

在往后社交媒体上了解到关于魔方机器人的话题，好奇的题出现，一个机器人如何拼好魔方？在人类益智玩具的璀璨星空中，魔方无疑是最为耀眼的存在之一。自发明魔方以来，这个由富于弹性的硬塑料制成的 6 面正方体，迅速风靡全球，成为了智力游戏界的传奇象征，与中国人发明的 “华容道”、法国人发明的 “独立钻石” 并称为智力游戏界的三大不可思议。在每一次转动魔方，都是一次对空间思维、逻辑推理、手眼协调能力的深度考验。

然而，科技的浪潮从未停止，当魔方遇上人工智能与先进的机械制造技术，魔方机器人成为了一个有趣的技术方向。算法方面，数据化的魔方无法成为三维的运算对象，只能转化成二维图去反复的尝试与运算最终得到解法。但无意义的运算会消耗大 量的运算时间，导致不必要的浪费。

目前已经有成熟的运算法，主流的有Thislethwaite，CFOP，Kociemba等等算法这次我们使用的是Kociemba算法。使用他的原因很简单，对于一个计算机来说，就像刚刚所说的数据化后的魔方依旧很难得解，但Kociemba算法为了便于理解，此处先不引出真实的二阶段算法阶段划分，假设我们的两个阶段分别是：

【还原角块、还原棱块，那么整个还原魔方的过程可以写成：打乱状态 ---(还原角块)---> 角块还原的状态 ---(还原棱块)---> 还原完毕】

这样，本来求解整个魔方的问题就变成了两个相对简单的子阶段，从而可以用计算机进行快速求解。其中更多的算法依旧是问题，也是后面该讲的。

算法方面简介完后机械方面也依旧是个难题，如理想环境下是简单又抽象的，实际中机械臂转动魔方将会因为各种因素导致各种问题出现，如魔方错位，跑偏缺步等等一系列问题，控制缺陷等等，接下来我将细细道来。

整体结构
====

对于单片机，是无法处理图像数据的，就算尝试用他来处理是相当缓慢的，甚至内存报厂。所以分为上位与下位机，下位主要以机械部分为主，通过上位的数据下载到下位机执行动作命令来控制机械设备完成工作，而上位机可以是电脑（树莓派）这种运算能力强的设备，通过摄像头传感器等模块设备来获取下位机将执行对象信息做相对应的计算，在这里上位机需要一个给用户直观的状态显示，这样的作用是方便用户对当前机器状态做了解并给出反馈。

下位机对于设备精密度有一定要求，但反馈只有接收到命令，无法判断命令的可行性和是否正常完成，所以在后面设计到了几种措施来实现。

基础框架
----

本次采用铝合金框架做作为主要框架，这款铝合金架是打造魔方机器人的关键基础组件。专门精心设计的，大小300mm\*251mm\*400mm ，这样的尺寸为魔方机器人内部各部件的合理布局提供了良好的空间框架。

从结构设计上看，铝合金材质赋予了它坚固耐用的特性，能够有效承受魔方机器人运行过程中产生的各种力量，保证整体结构的稳定性，减少因震动、碰撞等因素对机器人性能造成的影响。

![图片包含 游戏机, 运动, 房间
可能不正确。]()在实际组装中，中间的横杆可帮助我们更准确地定位电机机械臂、传感器等关键部件。可根据实际情况合理移动电机的安装位置，确保转动的顺畅性精准性，为魔方机器人快速、精准地转动魔方提供稳定动力支持。上杆也作为摄像头固定等方面的用处，同时，框架的规整结构也便于线路的布置与整理，我们可以提前规划线路走向，利用线槽等工具将各类线路有序排布，并且可以当作屏蔽层，避免线路与部件之间产生干涉，既保障了机器人内部的整洁有序，也为后期的维护检修带来便利。

此外，铝合金架的各个连接部位设计合理，通过使用合适的螺栓螺母进行紧固，必要时也可以快速调整位置等，可进一步快速调整。防止机器人在运行时出现抖动、松脱等情况，也怎加减震垫等、这样可以可靠地完成魔方复原任务。

-------

![图片包含 工程绘图

电路布局
----

因为各个硬件对于电源要求不同，使用采用多级变压方式，高压24V在降压6V电压给低压设备，同时用电阻隔离，起到保护电路设备等作用。在外场同时也为了方便搬运也单独设计了移动电源版，方便外场使用。

除去定义好的信号线，在其中合理的正负极也相当重要，不合理的布线将带来严重的后果。变压后的正负极直接连接这在理想化的情况下是没问题的，现实中高低压分离才是安全可靠的，高压设备的工作带来的波动会造成低变压不稳定而造成的烧板设备等问题。隔离后只需要高低压负极互连便可正常通信，但一个保险电阻还是不可缺少的的。

这里机械臂主要由步进电机和伺服电机为动力来源，伺服电机主要使用PWM控制，开发板可直接输出模拟信号直接控制，但步进电机不能直接控制，所以需要电机驱动器。本次采用DM542C驱动器，功耗小功能强大并且可编程等优势。驱动器需要输入脉冲方向和使能，脉冲是电机转动的量角度，方向为顺时逆时针旋转，使能为力的大小，这里主要使用的是角度量和方向，力在编程可直接设置最大值直接节省。在这次制作中步进电机方向问题较多，AB线项与控制器连接错误会造成方向不理想的问题，多次调整后理想化，才得以方便后续开发。

低压区主要为开发板和树莓派等运算处理的设备，之间主要为串口连接，这主要还是方便数据交互的统一性，细节方面将于代码部分讲解，摄像头舵机等模块全部由6/5V两类供电。并且以上述隔离。

### 图像获取：

通过获取到的图像数据，使用Python的OpenCV处理魔方每面状态，在传入魔方二阶还原算法得出还原公式，编码后传入下位机。下位机采用C语言编程编译机器码，主要功能为下载还原公式对设备进行操作流程（双臂还原魔方）。

通过机械臂三次转动魔方，一次拍摄两面，实现魔方六面颜色信息的获取，并且将魔方初始状态通过照片与数据文件存储起来。为提升图像质量，采集后的图像首先经过 **高斯模糊算法** 进行降噪处理，通过二维正态分布核函数平滑像素值，有效抑制环境光噪点与机械臂抖动导致的图像失真，在割成单面图像。因为位置是相对固定的，这样只需要相对位置将图片分割，这样系统只需要通过 **透视变换算法** 对单图进行矫正。

### 颜色识别：

颜色识别代码模块中，采用 **K-Means 聚类算法** 作为核心方案，该算法凭借独特的技术特性成为视觉系统的理想选择。对环境光照条件要求较低，无需依赖专业摄影棚级别的均匀光源，仅需**正常室内环境光**即可实现快速准确的色块识别，有效克服了传统颜色识别算法在复杂光照下易出现色偏、噪点干扰的问题。从工程实现角度看，K-Means 算法具有 **极低的计算复杂度**，空间和计算复杂度较低，经过有限步数就能够收敛得到聚类输出，能够自适应学习魔方色块的 RGB 值分布特征，准确度较高。

算法的步骤是：  
1、先随机选择K个初始的聚类中心

2、计算每个样本和这k个聚类中心的距离，按照最近原则将这些点分到这K个聚类中

3、重新计算每个聚类的均值，再进行划分

4、直到聚类结果没有变化时，算法收敛。

### 还原算法：

问题与解决优化
=======

机械电路
----

![图片包含 游戏机, 电路, 电缆
可能不正确。]()在实际研究过程中依旧会出现很多问题，因为初期的部分精度欠缺导致的失误常常出现，这并不理想。

最初问题常在机械臂动作规划中，理想动作关联线路连接和代码问题，规范的连线但AB交互依然会出现动作错误等问题，虽然会有人说重新构建代码或者一个一个动作去写这种，可是规范的结构和动作会给后期开发带来更大利益，对于后来者重新学习和在去优化节约更多时间。

![]()线路与代码规范后，依然出现了个问题，对于魔方与手指材质之间的摩擦力远远不够，这样会造成一个机械爪张开失去校准面而大面积下滑。这个过程中尝试增加机械指的合并力度，但需要更大的力反而需要速度更慢的伺服电机，这使得多种不利出现，如魔方被大力的手指夹飞，因为材料强度不够损坏机械结构，动作缓慢等等不利。这样的方法虽然可以用更好的结构材料解决，可这样会大幅度的增加不必要的重量，使得整体结构复杂难以维护。所以在这种情况尝试更换表面材质，这样在不缺失该有的材料强度情况下增加摩擦力。多次试验下来，2mm海绵垫是最符合预期的，通过U型环贴还能填补因为精度导致的手指合并中因向外展开，导致非平行的缺陷问题，大幅度减少了异常出现。

软件程序
----

![文本
可能不正确。]() 程序函数之间的互通常见的有内部端口，变量，外部端口，文件交互等方法，但这些中内部端口与变量这种交互会出现程序异常后无法保存当前数据，只有不知道原因的错误提示，这样对程序开发带来多种不便。而外部端口和文件交互类的遗留反而对程序开发更加有力，但因为外部端口交互需要搭建一个小环境等等，所以文件存储交互更妥当。

在选择以文件为交互的这个过程中，高速的处理会因为进程没有及时的退出而造成拥堵的报错，这个对于程序是很威胁的，所以及时的退出文件使得程序的可靠性成为关键，这个过程是艰难的。在合理的修改后得到旁边这段代码，安全的表现非常出色。
